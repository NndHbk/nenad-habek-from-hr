Privacy Policy

Application: KATICA Mail Hub

KATICA Mail Hub is a private personal application used by the authorized Google account owner.

Google account access

The application uses Google OAuth to request read-only access to Gmail. This access is used to retrieve and process mailbox information for personal information-management, search and automation functions requested by the authorized user.

Use of Google user data

Google user data obtained through this OAuth client is used only to provide the application's user-requested functionality. It is not sold and is not used for advertising.

The application does not use its Gmail read-only permission to send, modify or delete Gmail messages.

Storage and retention

Data may be retained on systems controlled by the application owner for personal retrieval, continuity, backup and automation purposes. Retention is limited to what is needed for those personal workflows.

Sharing

Google user data is not made publicly available. Processing and access are limited to the authorized user's personal systems and services used to provide the requested application functionality.

Security

Reasonable technical measures are used to protect OAuth credentials and locally retained data from unauthorized access.

Revoking access

The authorized user may revoke the application's Google account access at any time through the security and third-party access settings of the user's Google Account.

Google API Services User Data Policy

KATICA Mail Hub's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
